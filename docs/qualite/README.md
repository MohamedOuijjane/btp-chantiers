# Livrables Qualité Logicielle

Suivi des livrables du module QL, selon le cycle en V vu en cours.

| Étape du cycle | Livrable | Responsable | Échéance | Statut |
|---|---|---|---|---|
| 1. Initialisation | Note de cadrage | Chef de projet | 17/10/2026 | ✅ Livré |
| 2. Spécifications | Cahier des charges (besoins, user stories, critères d'acceptation) | Spécialiste métier | 31/10/2026 | ⏳ |
| 3. Conception | Dossier de conception (UML, architecture, contrats) | Architecte | 07/11/2026 | ⏳ |
| 4. Réalisation | Dossier de tests unitaires et d'intégration | Responsable qualité | 15/11/2026 | ⏳ |
| 5. Recette | Cahier de recette, fiches d'anomalies, PV de recette | Responsable qualité | 19/11/2026 | ⏳ |

Les anomalies sont tracées via les **issues GitHub** (modèle « Fiche d'anomalie »), ce qui remplace la main courante papier.
